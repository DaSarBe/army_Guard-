# 排衛哨勤務管理系統

單檔網頁應用（`index.html`），用來管理衛哨排班。不需要安裝、不需要伺服器，所有資料都存在瀏覽器的 `localStorage`。

## 功能

- **首頁**：操作步驟與特殊人員說明。
- **人員名單**：管理人員，點選星期（變紅色）代表該人員當天休假，排哨時自動排除。可清空名單。
- **新增人員**：一次貼上多個姓名（每行一人）批次加入。
- **自動排哨**：選 1～2 個值勤日期、起始時間、每班人數與哨點，按「開始自動排哨」。每班 2 小時、一天 12 班，會避開休假，並可勾選規則：
  - 避免同一天連續兩班
  - 優先避免隔天再次值勤
  - 儘量平均勤務次數
  - 站完 2 小時哨需休息 6 小時
- **手動排哨**：指定日期、時段與哨點，從可排人員中挑選，休假人員自動鎖定。
- **勤務結果**：可直接換人、刪除或新增勤務，缺額會在最上方提醒；支援複製（貼到 Excel）與列印。
- **歷史紀錄**：每次自動排哨都會留下一筆，可查看或清除。
- **資料備份**：匯出／匯入 JSON 備份檔（含人員設定、勤務結果、歷史紀錄）。

特殊人員：「主官管」完全不排勤務；「營外事故」不會被自動排入，只能在勤務結果手動指派。

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可（雙擊，或拖曳到瀏覽器視窗）。

若偏好用本機伺服器：

```bash
python3 -m http.server 8765
# 然後開啟 http://127.0.0.1:8765/index.html
```

網頁字型（Noto Sans TC）從 Google Fonts 載入；離線時會自動改用系統字型，功能不受影響。

## 資料與備份

- 資料存在「目前使用的瀏覽器、目前的網址（或檔案路徑）」下，換瀏覽器或清除網站資料就會消失。
- 請定期到「資料備份」匯出 JSON 備份檔，需要時再匯入（匯入會覆蓋目前所有資料）。

使用的 `localStorage` 鍵：`guard_people_v3`、`guard_roster_v3`、`guard_history_v3`、`guard_current_hist`、`guard_warn_v3`。

## 移植說明

本專案由 Claude Artifact 匯出的單檔網頁移植而來。已移除所有依賴 Artifact 環境的程式：

- `window.claude.use("db")`／`user`：原本的雲端同步（含快照監聽、寫入重試、唯讀判斷）整段移除，資料只使用 `localStorage`。
- `window.claude.use("downloads")`：移除，匯出備份改為原本就有的瀏覽器標準下載（`Blob` + `<a download>`）。

其餘功能與外觀維持原樣。
